Method Endpoint Description
GET /api/tasks Fetch all tasks (with optional filtering)
GET /api/tasks/:id Fetch single task by ID
POST /api/tasks Create new task
PUT /api/tasks/:id Update entire task
PATCH /api/tasks/:id/complete Toggle task completion status
DELETE /api/tasks/:id Delete task permanently
GET /health Server health check endpoint

💡 Challenges & Solutions

Challenge 1: Managing Multiple Developers

Problem: Potential merge conflicts and coordination issues

Solution: Implemented clear branch strategy, regular communication, and role-based feature separation

Challenge 2: Automated Testing with Database

Problem: Tests affecting production database

Solution: Used MongoDB Memory Server for isolated test environment

Challenge 3: CI/CD Pipeline Performance

Problem: Slow build times affecting development speed

Solution: Implemented dependency caching and parallel test execution (40% faster)

Challenge 4: Responsive Design Across Devices

Problem: Inconsistent UI on different screen sizes

Solution: Mobile-first approach with CSS Grid, Flexbox, and extensive testing
